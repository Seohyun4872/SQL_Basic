# SQL Basics

English · [한국어](README.ko.md)

BigQuery SQL study notes and exercises on querying, aggregation, data transformation, and joins.

## Context and contribution

This repository records study-group learning. It contains concept summaries, exercise responses, and practice records alongside the original assignment scaffolding. Prompts, reference examples, and linked teaching materials belong to their respective sources; they are not presented as original project designs.

Detailed notes are primarily in Korean. Coverage lists the uploaded material, not a claim that every exercise is complete or technically validated.

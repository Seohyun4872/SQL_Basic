## 학습 배경과 작성 범위

스터디 과정에서 작성한 개념 정리, 문제 풀이, 실습 기록과 원래 과제 양식이 함께 포함되어 있습니다. 과제 문항·참고 예시·강의 자료는 각 출처의 자료이며, 독립적으로 기획한 프로젝트와 구분합니다.

상세 노트는 주로 한국어로 작성되어 있습니다. 아래 목차는 업로드된 자료의 범위이며, 모든 과제를 완료했거나 기술적으로 검증했다는 의미는 아닙니다.

관심 있는 주제의 문서에서 개념 설명과 문제 풀이를 확인할 수 있습니다. 코드·이미지·수정 과정은 해당 문서에 남아 있는 범위에서 제공됩니다. 학습 단계의 기록으로, 운영 서비스나 완성된 분석 프로젝트와는 구분됩니다.
